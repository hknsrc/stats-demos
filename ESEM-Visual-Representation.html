What changes?

Secondary paths: fixed at zero

Primary loadingAllowed secondary paths (ESEM)

This CFA (ICM) schematic fixes secondary loadings at zero. If the true cross-loadings are nonzero, that restriction can worsen fit and inflate factor correlations.

Schematic example: an item with primary factor F1. Line width is illustrative; no parameters are estimated.

Teaching model, not statistical estimation. These are illustrative game scores, not CFI, TLI, RMSEA, or estimated correlations. ESEM is not automatically the preferred model; theory, fit, interpretability, identification, and parsimony matter.
How the game scores work

The original game's scoring rules are retained, but scores are shown only after all 12 items are placed. Each wrong primary assignment subtracts 10 points in both models. Changing the model never changes whether an assignment is correct. Returning any item to the pool hides both model scores until the assignment is complete again.

Fit score = max(0, round(100 − 10 × wrong assignments − c × cross-loading level))
c = 80 for CFA; c = 25 for ESEM
Inflation index = cross-loading level × k; k = 1.2 for CFA and 0.3 for ESEM

The coefficients are teaching choices, not fitted or empirically calibrated parameters. With zero cross-loadings, the two scores coincide by construction. The inflation index illustrates the effect of omitted secondary loadings only; it does not summarize every source of bias, including incorrect primary assignments.

Conceptual background: Asparouhov & Muthén (2009), Exploratory Structural Equation Modeling.
